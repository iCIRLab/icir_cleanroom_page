Abstract

When a hazardous gas leak occurs in a structured indoor environment such as a cleanroom, it is important to reach and remove the gas source rapidly while minimizing the need for personnel to enter the affected area. Cleanrooms with stringent cleanliness requirements, such as semiconductor front-end fabrication facilities, use vertical unidirectional airflow from the ceiling to a perforated floor. In these environments, the horizontal airflow component is negligible, leaving no wind-direction cues that indicate the direction of the gas source.

Most research on mobile robot-based gas source localization (GSL) relies on plumes generated by horizontal airflow and wind-direction measurements as key cues, while established benchmarks focus on warehouses, residential environments, and wind tunnels. To the best of our knowledge, no GSL evaluation has been reported for the vertical unidirectional airflow conditions found in cleanrooms. Moreover, existing studies typically assume that the search begins without prior information and focus on localization accuracy or concentration mapping. Consequently, how quickly a robot can reach a gas source using limited concentration measurements collected during routine patrols remains insufficiently explored.

This paper proposes a benchmark for a single gas source that evaluates the process from anomaly detection during a robot's patrol to the final source-position decision in the absence of wind-direction cues. In regions away from obstacles, gas concentration on the horizontal plane at sensor height is modeled as an isotropic Gaussian, since there is no horizontal airflow to skew the distribution. The robot measures concentrations at predefined locations during a low-resolution survey (LRS). Upon detecting an anomalous concentration, it switches to a high-resolution search (HRS), using a Gaussian Markov random field (GMRF) to estimate the concentration field and locate the source. Evaluation measures the time from the transition to HRS until the final source-position decision, together with the source localization error. Methods are compared by a Score that averages, over trials, the ratio of ideal travel time to HRS decision time, discounted by the localization error expressed in GMRF cells. HRS decision time, localization error, and the time to reach the final estimated position are reported as detailed metrics.

We randomly generated gas source positions, strengths, and distribution widths in an indoor environment with obstacles simulated using ROS 2, Gazebo, and Nav2. We compared six methods combining three search starting-point selection rules (the patrol location with the highest measured concentration, the concentration-weighted centroid of patrol locations, and the cell with the highest estimated mean) with two subsequent search strategies (selection of the cell with the highest estimated mean and spiral search). All methods were evaluated on the same 100 gas sources generated with fixed random seeds, and the 91 sources on which all six methods finished normally were used for comparison.

Combining the concentration-weighted centroid start with spiral search achieved the highest Score (0.311), followed by the highest-concentration patrol start with spiral search (0.277). For every starting-point rule, spiral search reached the source-position decision faster than selecting the cell with the highest estimated mean. Mean localization error was below 0.07 m for all six methods.

A centered sampling reference

The physical inlet is offset from the robot center. For this experiment, the horizontal sampling and recording reference is placed at the robot center (base_link). The body’s inlet offset is not applied to the sampled coordinates.

Concentration is sampled from a static 2D Gaussian field at the virtual sensor’s (x, y). Its value is relative and bounded between 0 and 1; the computation does not use height z.

Evaluation Metrics

Compare decision time and localization error together. Use an ideal travel-time reference to express the decision-time ratio.

Decision time

How quickly does the robot decide where the source is? Lower is better, alongside error.

T_HRS = t_decide − t_switch

HRS decision duration (s).

T_LRS

Localization error

How close is the final estimated source position to the true source? Lower is better.

E = ‖p̂ − p_src‖₂ = √[(x̂ − x_src)² + (ŷ − y_src)²]
E
Straight-line localization error (m).
p̂ = (x̂, ŷ)
Final estimated source coordinates in the map frame (m).
p_src
True source coordinates (x_src, y_src), used as ground truth for evaluation (m).

Euclidean norm: straight-line distance between the two positions.

If the true source lies in a non-navigable area (inside equipment, walls or safety margins), the robot cannot reach it, so the nearest reachable point replaces p_src as the reference.

How the final estimate is selected
j* = arg max c̄_j over HRS visits; p̂ = q(p_j*)
M_HRS
Indices of valid HRS measurement visits.
j*, c̄_j
Visit with the highest mean concentration, and the mean defined in Measurement.

The current branch freezes the cell associated with the highest recorded HRS mean concentration. Equal means retain the earlier record. GMRF estimates support exploration; the final logged position follows this measured-maximum rule.

03 / REFERENCE RATIO

Decision-time ratio

How fast is the decision relative to ideal travel time? Compare with position error.

η = T* / T_HRS; T* = L* / v_max
η
Dimensionless ideal-travel-time / decision-time ratio.
T*
Ideal time to traverse the reference shortest path at the configured maximum speed (s).
L*
Shortest feasible path length from the robot’s HRS-transition position to the true source (m).
v_max
Maximum speed configured for the robot in the experiment (m/s). Use that experiment’s setting.
T_HRS
Decision duration defined above (s); positive for this ratio.

T* is an evaluation reference. The ratio may exceed 1 when the robot decides the source location before an ideal traversal would finish. Interpret it together with localization error.

Reference-path conditions

Compute L* with the same map and navigation constraints across methods. T* omits acceleration, turning and stops. If the true source is unreachable, define a reachable reference endpoint separately before computing the ratio.

04 / AGGREGATE SCORE

Score

Average the trial-wise time ratios, each discounted by that trial’s localization error, to compare methods on the same trial set. Higher is better.

Score = (1/N) Σ η_i / (1 + E_i/d) = (1/N) Σ (T*_i / T_HRS,i) · d / (d + E_i)
N
Number of trials included in the comparison for each method. Use the same trial set across methods.
i
Trial index, from 1 to N.
η_i
Time ratio of trial i. Each trial is weighted equally.
T*_i
Ideal reference travel time for trial i (s).
T_HRS,i
HRS decision duration for trial i (s).
E_i
Localization error of trial i, as defined in 02 (m).
d
GMRF cell size, 0.5 m. Final estimates are cell centers, so this is the resolution of the estimate.

E_i/d is the error in GMRF cells: zero error (E_i = 0) keeps η_i, a one-cell error halves it, and a two-cell error leaves one third. No success threshold is applied. Per-trial values are averaged, rather than dividing the average reference time by the average decision time.

Supplementary measure: time to estimated source
T_arrival = t_arrival − t_switch
t_arrival
Robot’s arrival time at the final estimated source position under the stated navigation criterion (simulation s).
t_switch
HRS transition time (simulation s).
T_arrival
Elapsed time from HRS transition through decision and approach to arrival (s).

This supplementary measure evaluates physical approach. Report it with localization error; arrival at an estimated position does not establish arrival at the true source.

초록

클린룸과 같은 구조화된 실내 환경에서 유해가스 누출이 발생하면, 작업자의 접근을 최소화하면서 가스원에 신속히 도달해 제거하는 것이 중요하다. 반도체 전공정 팹과 같이 높은 청정도가 요구되는 클린룸은 천장에서 타공 바닥으로 공기가 흐르는 수직 단방향 기류 방식을 사용하며, 이 환경에서는 수평 방향 기류 성분이 거의 없어 가스원의 방향을 알려주는 풍향 단서를 얻을 수 없다.

이동 로봇 기반 가스원 위치 추정(GSL) 연구는 대부분 수평 기류가 만드는 플룸과 풍향 측정을 핵심 단서로 삼으며, 대표적인 벤치마크 역시 창고·주택·풍동 환경을 대상으로 한다. 우리가 아는 한 클린룸의 수직 단방향 기류 환경을 대상으로 한 GSL 평가는 보고되지 않았다. 또한 기존 연구는 사전 정보 없이 탐색을 시작하는 상황을 가정하고 위치 정확도나 농도 지도 작성에 초점을 두어, 평시 순찰로 얻은 제한적인 농도 정보를 활용해 가스원에 얼마나 빨리 도달하는가는 충분히 다뤄지지 않았다.

본 논문은 단일 가스원을 대상으로, 풍향 단서가 없는 환경에서 순찰 중 이상을 감지한 로봇이 최종 가스원 추정 위치를 결정하기까지의 과정을 평가하는 벤치마크를 제안한다. 장애물에서 떨어진 영역에서는 분포를 한쪽으로 치우치게 할 수평 기류가 없으므로, 센서 높이 수평 단면의 가스 농도를 등방성 가우시안으로 모델링한다. 로봇은 저해상도 순찰(LRS)로 사전에 정의된 지점의 농도를 측정하고, 이상 농도가 검출되면 고해상도 탐색(HRS)으로 전환하여 가우시안 마르코프 랜덤 필드(GMRF)로 농도를 추정하여 가스원을 찾는다. 평가는 탐색 전환부터 최종 가스원 추정 위치 결정까지의 시간과 위치 추정 오차로 한다. 방법 간 비교에는 이상적 이동시간을 HRS 위치 결정 시간으로 나눈 비율에 GMRF 셀 단위의 위치 오차를 반영해 시행별로 평균한 Score를 사용하며, HRS 위치 결정 시간, 위치 추정 오차, 최종 추정 위치까지의 도착 시간은 상세 지표로 제시한다.

ROS 2, Gazebo, Nav2 기반 시뮬레이션의 장애물 실내 환경에서 가스원의 위치, 세기, 분포 폭을 무작위로 생성하였다. 탐색 시작 위치 선정 방법 3가지(순찰 최고 농도 지점, 순찰 농도 가중 무게중심, 추정 평균 최대 셀)와 이후 탐색 전략 2가지(추정 평균 최대 셀 선택, 나선 탐색)를 조합한 6개 방법을, 시드를 고정한 동일 가스원 100개 중 6개 방법이 모두 정상 종료된 91개에 대해 비교하였다.

그 결과 순찰 농도 가중 무게중심에서 시작해 나선 탐색을 수행한 방법이 가장 높은 Score(0.311)를 보였고, 순찰 최고 농도 지점에서 시작한 나선 탐색(0.277)이 뒤를 이었다. 모든 시작 위치 규칙에서 나선 탐색은 추정 평균 최대 셀 선택보다 빠르게 가스원 위치를 결정했으며, 6개 방법 모두 평균 위치 추정 오차가 0.07 m 미만이었다.

j번째 방문에서 받은 k번째 농도 샘플 (상대값, 0~1).
n_j
해당 방문의 측정 구간 동안 실제 수신한 샘플 수.
c̄_j
한 개 관측값으로 기록하는 평균 농도.
방문별 기록

측정 시작 시점의 위치 · 평균 농도 · 실제 샘플 수 · LRS/HRS 단계 · 측정 이벤트 시각. 기록 위치는 GMRF 셀에 대응시켜 농도 분포 갱신에 사용합니다.

FROM OBSERVATIONS TO PERFORMANCE

평가지표

위치 결정 시간과 위치 오차를 함께 비교하고, 이상적 이동 기준시간으로 위치 결정 시간의 비율을 나타냅니다.

01 / 시간 · s

위치 결정 시간

가스원이 어디인지 얼마나 빨리 결정했는가? 위치 오차와 함께 비교하며, 낮을수록 좋습니다.

T_HRS = t_decide − t_switch
T_HRS
HRS 위치 결정 소요 시간 (s).
t_switch
로봇이 HRS로 전환한 시뮬레이션 시각 (s).
t_decide
로봇이 최종 가스원 추정 좌표를 결정한 시뮬레이션 시각 (s).

모든 방법은 동일한 LRS 절차를 사용합니다. 주 시간 비교는 HRS 전환부터 최종 가스원 위치 결정까지로 한정합니다.

LRS 및 전체 시간 정의
T_LRS = t_switch − t_start; T_total = T_LRS + T_HRS
t_start
순찰 시작 시각 (시뮬레이션 초).
T_LRS
순찰 시작부터 HRS 전환까지의 시간. 전환 대기가 있다면 포함 (s).
T_total
순찰 시작부터 최종 위치 결정까지의 시간 (s). 이후 접근 시간은 제외.
02 / 정확도 · m

위치 추정 오차

최종 추정 위치가 실제 가스원에 얼마나 가까운가? 낮을수록 좋습니다.

E = ‖p̂ − p_src‖₂ = √[(x̂ − x_src)² + (ŷ − y_src)²]
E
직선거리로 계산한 위치 추정 오차 (m).
p̂ = (x̂, ŷ)
지도 좌표계의 최종 가스원 추정 좌표 (m).
p_src
평가 기준인 실제 가스원 좌표 (x_src, y_src), Ground Truth (m).
‖·‖₂
유클리드 노름. 두 위치 사이의 직선거리.

실제 가스원이 주행 불가능한 영역(설비 내부·벽·안전거리)에 있으면 로봇이 도달할 수 없으므로, 가장 가까운 도달 가능 지점을 p_src 대신 기준으로 사용합니다.

최종 추정 좌표를 결정하는 방법
j* = arg max c̄_j over HRS visits; p̂ = q(p_j*)
M_HRS
유효한 HRS 측정 방문 번호의 집합.
j*, c̄_j
평균 측정 농도가 최대인 방문 번호와 Measurement에서 정의한 평균 농도.
p_j, q(·)
방문 시 기록 위치 (m). q는 그 위치를 대응하는 GMRF 셀 중심으로 변환합니다.

현재 브랜치는 HRS 평균 측정 농도가 가장 높았던 지점의 셀을 최종 위치로 확정합니다. 동점이면 먼저 기록된 측정을 유지합니다. GMRF 추정은 탐색에 활용되며, 최종 기록 좌표는 이 최대 측정값 규칙을 따릅니다.

03 / 기준시간 비율

위치 결정 시간 비율

이상적 이동시간을 기준으로 위치 결정 속도를 비교합니다. 위치 오차와 함께 평가합니다.

η = T* / T_HRS; T* = L* / v_max
η
이상적 이동 기준시간을 위치 결정 시간으로 나눈 무차원 비율.
T*
기준 최단경로를 설정 최고속도로 이동하는 이상적 시간 (s).
L*
HRS 전환 시점의 로봇 위치에서 실제 가스원까지의 최단 주행 경로 길이 (m).
v_max
해당 실험에 사용하는 로봇에 설정된 최고속도 (m/s). 실험별 설정값을 사용합니다.
T_HRS
앞에서 정의한 위치 결정 시간 (s). 비율 계산 시 양수여야 합니다.

T*는 평가를 위한 기준시간입니다. 로봇이 이상적 이동시간보다 먼저 가스원 위치를 결정하면 비율은 1을 넘을 수 있습니다. 위치 오차와 함께 해석합니다.

기준 경로의 조건

L*는 방법 간 동일한 지도와 주행 제약으로 계산합니다. T*에는 가감속·회전·정지 시간이 포함되지 않습니다. 실제 가스원이 도달 불가능한 위치라면, 비율을 계산하기 전에 도달 가능한 기준점을 별도로 정의해야 합니다.

04 / 오차 반영 시간 효율

Score

시행별 시간 비율에 그 시행의 위치 오차를 반영한 뒤 평균하여, 동일한 시행 집합에서 방법별 성능을 비교합니다. 높을수록 좋습니다.

Score = (1/N) Σ η_i / (1 + E_i/d) = (1/N) Σ (T*_i / T_HRS,i) · d / (d + E_i)
N
방법별 비교에 포함하는 시행 수. 방법 간 동일한 시행 집합을 사용합니다.
i
시행 번호. 1부터 N까지의 각 시행을 나타냅니다.
η_i
i번째 시행의 시간 비율. 모든 시행을 동일한 비중으로 평균합니다.
T*_i
i번째 시행의 이상적 이동 기준시간 (s).
T_HRS,i
i번째 시행의 HRS 위치 결정 소요 시간 (s).
E_i
i번째 시행의 위치 추정 오차 (m). 02에서 정의한 값입니다.
d
GMRF 셀 크기 0.5 m. 최종 추정 위치는 셀 중심이므로 추정의 분해능에 해당합니다.

E_i/d는 오차를 GMRF 셀 수로 나타낸 값입니다. 오차가 0이면 η_i를 그대로, 1셀 오차면 절반, 2셀 오차면 1/3을 반영합니다. 성공 임계값은 두지 않습니다. 평균 기준시간을 평균 결정 시간으로 나누지 않고, 시행별 값을 계산한 뒤 평균합니다.

보조 지표: 추정 위치 도착 시간
T_arrival = t_arrival − t_switch
t_arrival
주행 도착 기준에 따라 로봇이 최종 추정 위치에 도착한 시각 (시뮬레이션 s).
t_switch
HRS 전환 시각 (시뮬레이션 s).
T_arrival
HRS 전환부터 위치 결정·접근을 거쳐 도착할 때까지의 시간 (s).

실제 접근 성능을 평가할 때 추가하는 보조 지표입니다. 추정 위치에 도착해도 실제 가스원에 도착한 것은 아닐 수 있으므로 위치 오차와 함께 제시합니다.

다음 결과에서는 공통 시드 91개에 대해 M1–M6를 Score로 비교하고, 위치 오차와 위치 결정 시간은 상세 결과에 제공합니다. 위치 결정 시간은 도착과 구분하여 위치 결정 이벤트를 기준으로 계산했습니다.
